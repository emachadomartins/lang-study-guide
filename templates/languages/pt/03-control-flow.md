## Exercícios

1. **FizzBuzz** — De 1 a 100: múltiplos de 3 imprimem `Fizz`, de 5 `Buzz`, de ambos `FizzBuzz`, os outros o próprio número.
2. **Tabuada** — Imprima a tabuada de 1 a 10 formatada em colunas alinhadas.
3. **Números primos** — Liste todos os primos até N usando loops aninhados. Depois, implemente o Crivo de Eratóstenes.
4. **Jogo de adivinhação** — O programa sorteia um número de 1 a 100; o usuário chuta até acertar, recebendo dicas "maior"/"menor". Conte as tentativas.
5. **Classificador com match** — Dada uma nota de 0 a 10, retorne o conceito (A–F) usando switch/match com intervalos.
6. **Pirâmide** — Dado N, desenhe uma pirâmide de asteriscos com N linhas.
