## Exercises

1. **Ready to go** — Install the language, create a project with the CLI and run Hello World.
2. **Arguments** — Write a program that takes the user's name as a command-line argument and prints `Hello, <name>!`. Without an argument, it prints `Hello, world!`.
3. **Interactive input** — Read a name from the keyboard (stdin) and greet the user.
4. **Explore the toolchain** — Run the formatter and the linter on a deliberately badly formatted file and note what changed.
