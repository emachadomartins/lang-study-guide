## Exercises

1. **BMI calculator** — Read weight (kg) and height (m), compute the BMI, and print it with 2 decimal places plus its classification.
2. **Temperature converter** — Convert Celsius ↔ Fahrenheit ↔ Kelvin.
3. **String manipulation** — Given a sentence, print: number of characters, number of words, the sentence reversed, and the sentence in uppercase.
4. **Type limits** — Print the largest and smallest value of each integer type and observe what happens when you add 1 to the largest.
5. **Safe parsing** — Read a string from the user and try to convert it to an integer; handle invalid input without crashing the program.
