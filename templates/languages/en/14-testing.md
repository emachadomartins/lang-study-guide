## Exercises

1. **Test what you built** — Write tests for the Luhn validator (chapter 04) and the balanced brackets checker (chapter 05), including edge cases.
2. **Table-driven** — Test FizzBuzz with a single parameterized test.
3. **Mock** — Test a function that looks up a postal code (chapter 13) without hitting the network, using a mock/fake.
4. **TDD** — Writing the tests first, implement a function that converts Arabic numbers to Roman numerals (1–3999).
5. **Coverage** — Generate the coverage report and reach 90%+ on the bank account module (chapter 06).
