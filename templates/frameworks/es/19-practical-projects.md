# 19 · Proyectos prácticos

Después de TaskFlow, proyectos independientes para consolidar lo aprendido. Elige los de tu categoría.

## 🖥️ Backend web

1. **Acortador de URLs** · *Principiante* — Acorta, redirige y cuenta visitas, con expiración.
2. **E-commerce simplificado** · *Intermedio* — Catálogo, carrito, pedido con stock transaccional y pago simulado vía webhook.
3. **Chat con salas** · *Avanzado* — WebSocket, historial persistido, presencia en línea.
4. **Plataforma multi-tenant** · *Avanzado* — Organizaciones aisladas, roles, auditoría y rate limiting por tenant.

## 🎨 Frontend web

1. **Panel del clima** · *Principiante* — Búsqueda por ciudad, pronóstico de 5 días, favoritos persistidos.
2. **Clon de Kanban** · *Intermedio* — Arrastrar y soltar, columnas personalizables, persistencia.
3. **E-commerce** · *Intermedio* — Catálogo con filtros en la URL, carrito, checkout en varios pasos, SEO.
4. **Editor colaborativo** · *Avanzado* — Edición en tiempo real por varios usuarios, con indicadores de presencia.

## 📱 Móvil / Escritorio

1. **Lista de compras offline** · *Principiante* — Funciona sin conexión y sincroniza al reconectar.
2. **Seguimiento de hábitos** · *Intermedio* — Notificaciones locales, gráficos de progreso, temas.
3. **App de fotos** · *Intermedio* — Cámara, galería, geolocalización, subida.
4. **Cliente de chat** · *Avanzado* — Notificaciones push, tiempo real, multimedia.

## 📊 Datos / ML

1. **Análisis exploratorio** · *Principiante* — Un dataset público (p. ej. data.gov, data.europa.eu, Kaggle) con limpieza, estadísticas y visualizaciones.
2. **Pipeline ETL** · *Intermedio* — Ingesta incremental desde una API pública, transformación y carga en formato columnar.
3. **Modelo predictivo** · *Intermedio* — Entrenar, evaluar, versionar y servir un modelo mediante una API.
4. **Procesamiento a escala** · *Avanzado* — Procesar un dataset más grande que la memoria, con particionamiento y paralelismo.

## Checklist de calidad (para cada proyecto)

- [ ] Estructura idiomática del framework
- [ ] Validación y manejo de errores
- [ ] Pruebas automatizadas (unitarias + integración)
- [ ] Configuración por entorno, sin secretos en el código
- [ ] Logs útiles
- [ ] README que explique cómo ejecutarlo
- [ ] Build de producción / contenedor funcionando
