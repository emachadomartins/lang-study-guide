## Ejercicios

1. **Primer proyecto** — Crea el proyecto `taskflow`, ejecútalo y cambia el mensaje/pantalla de bienvenida a "TaskFlow".
2. **Explora la estructura** — Para cada archivo generado, escribe en una línea para qué sirve (guarda las notas en el README de tu proyecto).
3. Construye el primer "hola" de TaskFlow en tu categoría:
   - 🖥️ **Backend:** `GET /health` que devuelva `{"status": "ok"}`.
   - 🎨 **Frontend** / 📱 **Móvil:** una pantalla inicial con el título "TaskFlow" y una lista fija de 3 tareas.
   - 📊 **Datos/ML:** genera/carga un dataset de 1.000 tareas ficticias (con todos los campos del dominio) y muestra las 5 primeras filas.
