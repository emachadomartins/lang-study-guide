# 19 · Practical projects

After TaskFlow, standalone projects to consolidate what you learned. Pick the ones for your category.

<!-- 🤖 Keep only the section for the framework's category (for "Other", create 4 equivalent projects). For each project, add "Suggested libraries" (real ones) and "Framework features you will practice". -->

## 🖥️ Backend web

1. **URL shortener** · *Beginner* — Shortens, redirects and counts visits, with expiration.
2. **Simplified e-commerce** · *Intermediate* — Catalog, cart, order with transactional stock and a simulated payment via webhook.
3. **Chat with rooms** · *Advanced* — WebSocket, persisted history, online presence.
4. **Multi-tenant platform** · *Advanced* — Isolated organizations, roles, auditing and per-tenant rate limiting.

## 🎨 Frontend web

1. **Weather dashboard** · *Beginner* — Search by city, 5-day forecast, persisted favorites.
2. **Kanban clone** · *Intermediate* — Drag and drop, custom columns, persistence.
3. **E-commerce** · *Intermediate* — Catalog with filters in the URL, cart, multi-step checkout, SEO.
4. **Collaborative editor** · *Advanced* — Real-time editing by multiple users, with presence indicators.

## 📱 Mobile / Desktop

1. **Offline shopping list** · *Beginner* — Works offline and syncs when the connection comes back.
2. **Habit tracker** · *Intermediate* — Local notifications, progress charts, themes.
3. **Photo app** · *Intermediate* — Camera, gallery, geolocation, upload.
4. **Chat client** · *Advanced* — Push notifications, real time, media.

## 📊 Data / ML

1. **Exploratory analysis** · *Beginner* — A public dataset (e.g. data.gov, data.europa.eu, Kaggle) with cleaning, statistics and visualizations.
2. **ETL pipeline** · *Intermediate* — Incremental ingestion from a public API, transformation and loading into a columnar format.
3. **Predictive model** · *Intermediate* — Train, evaluate, version and serve a model through an API.
4. **Processing at scale** · *Advanced* — Process a dataset larger than memory, with partitioning and parallelism.

## Quality checklist (for each project)

- [ ] Idiomatic framework structure
- [ ] Validation and error handling
- [ ] Automated tests (unit + integration)
- [ ] Per-environment configuration, no secrets in code
- [ ] Useful logs
- [ ] README explaining how to run it
- [ ] Production build / container working
