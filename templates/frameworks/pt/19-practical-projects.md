# 19 · Projetos práticos

Depois do TaskFlow, projetos independentes para consolidar o aprendizado. Escolha os da sua categoria.

## 🖥️ Backend web

1. **Encurtador de URLs** · *Iniciante* — Encurta, redireciona e conta acessos, com expiração.
2. **E-commerce simplificado** · *Intermediário* — Catálogo, carrinho, pedido com estoque transacional e pagamento simulado via webhook.
3. **Chat com salas** · *Avançado* — WebSocket, histórico persistido, presença online.
4. **Plataforma multi-tenant** · *Avançado* — Organizações isoladas, papéis, auditoria e rate limit por tenant.

## 🎨 Frontend web

1. **Dashboard de clima** · *Iniciante* — Busca por cidade, previsão de 5 dias, favoritos persistidos.
2. **Clone de Kanban** · *Intermediário* — Arrastar e soltar, colunas customizáveis, persistência.
3. **E-commerce** · *Intermediário* — Catálogo com filtros na URL, carrinho, checkout em várias etapas, SEO.
4. **Editor colaborativo** · *Avançado* — Edição em tempo real por vários usuários, com indicadores de presença.

## 📱 Mobile / Desktop

1. **Lista de compras offline** · *Iniciante* — Funciona offline e sincroniza ao reconectar.
2. **Rastreador de hábitos** · *Intermediário* — Notificações locais, gráficos de progresso, temas.
3. **App de fotos** · *Intermediário* — Câmera, galeria, geolocalização, upload.
4. **Cliente de chat** · *Avançado* — Push notifications, tempo real, mídia.

## 📊 Dados / ML

1. **Análise exploratória** · *Iniciante* — Dataset público (ex.: data.gov, data.europa.eu, Kaggle) com limpeza, estatísticas e visualizações.
2. **Pipeline ETL** · *Intermediário* — Ingestão incremental de uma API pública, transformação e carga em formato colunar.
3. **Modelo preditivo** · *Intermediário* — Treinar, avaliar, versionar e servir um modelo via API.
4. **Processamento em escala** · *Avançado* — Processar um dataset maior que a memória, com particionamento e paralelismo.

## Checklist de qualidade (para cada projeto)

- [ ] Estrutura idiomática do framework
- [ ] Validação e tratamento de erros
- [ ] Testes automatizados (unitário + integração)
- [ ] Configuração por ambiente, sem segredos no código
- [ ] Logs úteis
- [ ] README com como rodar
- [ ] Build de produção / container funcionando
