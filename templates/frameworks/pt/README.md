## Projeto-guia: TaskFlow

Os exercícios dos capítulos 01 a 15 constroem **um único projeto, aos poucos**. O domínio é o mesmo para todos os frameworks, para que você possa compará-los:

- **Usuário**: nome, e-mail, senha
- **Projeto**: nome, descrição, dono (usuário), membros
- **Tarefa**: título, descrição, status (`todo`, `in_progress`, `done`), prioridade (`low`, `medium`, `high`), prazo, tags, responsável, data de criação, data de conclusão

Como o projeto-guia aparece em cada categoria:

| Categoria | O que você constrói |
|-----------|---------------------|
| 🖥️ Backend web | API REST/GraphQL do TaskFlow |
| 🎨 Frontend web | SPA/site do TaskFlow consumindo uma API (pode ser mock) |
| 📱 Mobile/Desktop | App do TaskFlow com armazenamento local e sincronização |
| 📊 Dados/ML | Análise e modelo sobre um histórico de tarefas: prever quais vão atrasar |
