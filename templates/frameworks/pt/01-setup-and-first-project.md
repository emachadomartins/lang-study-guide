## Exercícios

1. **Primeiro projeto** — Crie o projeto `taskflow`, rode-o e altere a mensagem/tela inicial para "TaskFlow".
2. **Explorar a estrutura** — Para cada arquivo gerado, escreva em uma linha para que serve (anote no README do seu projeto).
3. Faça o primeiro "olá" do TaskFlow na sua categoria:
   - 🖥️ **Backend:** `GET /health` retornando `{"status": "ok"}`.
   - 🎨 **Frontend** / 📱 **Mobile:** tela inicial com o título "TaskFlow" e uma lista fixa de 3 tarefas.
   - 📊 **Dados/ML:** gere/carregue um dataset de 1.000 tarefas fictícias (com todos os campos do domínio) e mostre as 5 primeiras linhas.
